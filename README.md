# Análise da Qualidade do Ar na Região Metropolitana do Rio de Janeiro

## Sobre o projeto

Este projeto tem como objetivo realizar uma análise temporal dos dados de monitoramento da qualidade do ar na Região Metropolitana do Rio de Janeiro referentes ao período de 2020 a 2025, utilizando informações disponibilizadas pelo Instituto Estadual do Ambiente (INEA).

A pesquisa busca investigar o comportamento temporal das concentrações de poluentes atmosféricos, avaliar a disponibilidade dos dados das estações de monitoramento e identificar episódios de ultrapassagem dos padrões de qualidade do ar com base na Resolução CONAMA 506/2024.

## Objetivos

- Analisar dados de monitoramento da qualidade do ar.
- Avaliar a disponibilidade e a cobertura temporal dos dados.
- Investigar padrões de concentração dos poluentes.
- Identificar episódios de ultrapassagem dos limites de referência.
- Explorar variações temporais e sazonais.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Fonte dos dados

Dados brutos de monitoramento da qualidade do ar disponibilizados pelo Instituto Estadual do Ambiente (INEA).

## Análises desenvolvidas

O projeto contempla análises de diferentes poluentes atmosféricos, incluindo material particulado (PM10 e PM2.5) e ozônio (O₃) nos anos de 2020 à 2025.

São utilizadas técnicas de análise exploratória, tratamento de dados, avaliação de cobertura, análise temporal e visualização gráfica.

## Organização

Os notebooks estão organizados de acordo com as análises realizadas ao longo da pesquisa para cada poluente.
